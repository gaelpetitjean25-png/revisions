Progression

Sauvegarder sur GitHub

Le bouton « Sauvegarder » enregistre la progression directement dans le dépôt GitHub. Sur l'autre appareil, « Charger » récupère la dernière sauvegarde — la même adresse GitHub, la même donnée. Une seule fois : ajoute ton jeton (clé d'accès) ci-dessous sur chaque appareil qui doit pouvoir sauvegarder (pas nécessaire pour juste charger).

Synchro automatique entre appareils

Une tentative de synchro automatique via des services gratuits — moins fiable que le bouton GitHub ci-dessus, garde-le en secours seulement.
La synchro n'est pas activée sur cet appareil.

Sauvegarde manuelle (fichier)

La progression est enregistrée automatiquement sur cet appareil. Télécharge un fichier de sauvegarde — ton téléphone te proposera de l'enregistrer directement dans Google Drive, sans rien connecter dans l'appli.
Ou avec un code texte à copier-coller
